# PetFlow AI

SaaS multi-tenant inteligente para o mercado pet.

## Stack

- **Backend:** Django 5.1 LTS + DRF + Celery + Redis
- **Frontend:** Next.js 15 + TanStack Query + Zustand + shadcn/ui
- **Banco:** PostgreSQL 16
- **Infra:** Docker + Docker Compose

## Estrutura

- `backend/` — API Django
- `frontend/` — Painel Next.js
- `docs/` — Documentação
